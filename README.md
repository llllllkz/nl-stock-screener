# 智选 · 自然语言选股与策略解释器

把投资者的模糊语言（如「经营改善、估值合理、走势相对稳定」）翻译成**可检查、可修改、可执行**的数据条件，
基于 **iFinD 真实数据**完成确定性筛选，并对每只股票给出**入选依据、排除原因、条件变化的敏感性影响**。

## 快速开始

```bash
cd app
npm install
npm run dev        # http://localhost:7100
npm test           # 引擎单元测试（vitest，14 例）
npm run build      # 生产构建 → app/dist（纯静态，可部署任意静态托管）
```

环境要求：Node.js 20+。无后端、无环境变量、无任何 API Key 提交到仓库——数据以快照 JSON 形式随仓库分发。

## 主链路（对应题目要求）

1. **意图澄清**：自然语言 → AI 解析层产出「理解 + 歧义澄清选项 + 不支持意图 + 合规提示」。
   例如「经营改善」需用户确认是「增速转正」还是「改善加速」；「高股息」因数据快照无分红字段被**如实标记为不支持**，不静默忽略。
2. **结构化条件**：每条条件标注来源（AI / 手动）、口径（悬停查看字段与时点），支持改阈值、改比较符、启停、删除、手动新增。
3. **冲突识别**：① 逻辑互斥（同一指标区间无交集）；② 结果为空时定位「约束最强」的条件并给出放松建议；③ 结果过少（≤2 只）时提示统计意义有限。
4. **可解释结果**：入选 / 排除 / **无法判定**（数据缺失单独成栏，绝不静默当作不通过）三分；
   每只股票逐条列出「实际值 vs 阈值」的判定过程，可回到原始字段。
5. **敏感性分析**：每条条件放松 / 收紧约 25% 后入选数量的变化（负值阈值方向已校正）。
6. **后续动作**：结果对比（多股票指标对照表）、策略保存 / 载入、转为监控任务（localStorage 本地持久化，模拟边界已如实标注）。

## 职责边界（AI vs 确定性引擎 vs 数据工具）

| 层 | 职责 | 不做的事 |
| --- | --- | --- |
| AI 解析层 `app/src/engine/parser.ts` | 模糊语言 → 结构化条件**草案**；识别歧义、不支持意图、合规表述 | 不做任何筛选计算；不输出买卖建议/涨跌预测/收益承诺 |
| 确定性引擎 `app/src/engine/screener.ts` | 条件 × 数据 → 逐条件判定、理由、冲突、敏感性；所有结论可追溯到字段值 | 不理解自然语言；不「润色」结论 |
| 数据工具 iFinD（agent-gw 插件） | 提供行情 / 财务指标真实数据 | 数据缺失时引擎只标记「无法判定」，不补造 |

本仓库中的解析层是**透明的规则式实现**，其输入输出契约与 LLM 解析器等价（`parseIntent(raw) → ParseResult`），
生产环境可用大模型替换内部实现而契约不变——这也是本设计对「AI 角色」的回答：AI 负责**翻译与澄清**，裁决权交给可复核的确定性引擎和用户。

## 数据来源与口径（关键数字可追溯）

- 来源：iFinD（同花顺）经由 agent-gw 插件调用，获取日 **2026-10-02**；原始 CSV 存于 `data_raw/`（49 只 × 5 组）。
- 样本池：49 只跨行业 A 股代表样本（消费/银行/保险/医药/科技/能源/制造/公用等），**非全市场**。
- 行情：2025-10-09 至 2026-09-30 前复权日线 → 年化波动率（日对数收益 std × √244）、最大回撤、60/120 日涨跌幅。
- 财务：2026 半年报（20260630）→ ROE（未年化）、净利率、毛利率、营收/归母/扣非同比；2025 年报（20251231）→ 静态 PE 分母 EPS、增速对比基数。
- 静态 PE = 2026-09-30 收盘价 ÷ 2025 年报基本 EPS；**EPS ≤ 0（亏损）时不给出 PE**，相关股票进入「无法判定」栏（示例：万科 A、中国国航）。
- 派生指标「净利增速变化」= 2026H1 归母同比 − 2025 年报归母同比，> 0 表示提速。
- 复现：`python fetch_data.py`（需本机 agent-gw 环境）→ `python build_snapshot.py` → 生成 `app/src/data/stocks.json`。

## 合规设计

- 命中「必涨 / 稳赚 / 买入 / 目标价 / 预测会涨」等表述时，界面弹出**合规边界提示**且不生成对应输出；
- 全站不输出确定性涨跌预测、收益承诺或买卖建议；事实（字段值）、推断（条件映射）、不确定信息（缺失/无法判定）分区呈现；
- 数据缺失、接口失败、口径不适用时不静默生成「正常」结论。

## 已知边界与未做事项

- 样本池 49 只为代表样本而非全 A 股；股息率、市值、资金流向字段未接入（界面会如实拒绝相关意图）。
- 「监控任务」仅本地保存监控定义（localStorage），未接入真实的定时调度与推送。
- 历史回测未实现：需要逐日历史成分与 point-in-time 财务快照，本期数据接口条件下做不到不掺假的回测，故明确不做。
- 财务指标以半年报/年报为期，ROE 未年化；不同行业 PE 口径可比性有限（如银行低 PE 为行业特征）。
- 解析层为规则实现，同义表达覆盖有限；接口契约已为替换 LLM 预留。

## 仓库结构

```
app/                  React + TS + Vite + Tailwind + shadcn/ui 前端（产品本体）
  src/engine/         parser.ts（AI 层）/ screener.ts（确定性引擎）/ metrics.ts（指标口径注册表）
  src/data/stocks.json  真实数据快照（含 meta 口径说明）
  src/sections/       六步主链路 UI
fetch_data.py         iFinD 批量取数脚本
build_snapshot.py     快照构建（含指标计算与口径定义）
data_raw/             iFinD 原始返回 CSV（可追溯证据）
docs/AI_USAGE.md      AI 使用与验证记录
docs/TESTING.md       测试说明
```
